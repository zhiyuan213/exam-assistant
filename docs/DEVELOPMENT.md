# 开发预览交付说明

## 已实现

可独立导入的 uni-app 微信小程序、H5预览、Spring Boot后端、数据库脚本、Docker配置、GitHub CI；创建计划/生成阶段/任务打卡/统计闭环。首页分享好友使用微信原生分享；朋友圈通过微信菜单入口引导。复制目前是产品介绍文字；真实小程序 URL Link 与带小程序码海报需要后端和发布账号配置，未伪造链接或小程序码。

规则引擎以每日分钟预算和科目权重生成通用路线。模板是初始内容，不是完整教学方案。Redis 暂作可选服务，尚未接入业务缓存。订单表与商品表已准备，支付接入未实现。

## 验证

- Java 17 / Spring Boot 3.5.16：规则引擎预算、连续阶段、短周期与参数边界测试。
- API集成：登录、创建、任务读写、重复打卡、撤销、记录、未登录访问和跨用户隔离、未开通支付拒绝。
- 实际JAR启动及HTTP检查：生成30天每日90分钟计划、读取当天任务、完成任务后记录90分钟。
- Node 22：本地计划算法预算/日期/科目校验测试。
- 微信小程序与H5生产构建。
- 手机尺寸H5实际创建180天计划、打卡96分钟数学任务，记录显示1.6小时、1项任务、连续1天。
- 应用用户UI设计后，验证独立生成完成页、计划总览/阶段切换、完成任务筛选和统计环形图；公务员144分钟任务完成后显示2.4小时。

本机 Docker Engine 未启动，因此 Compose / MySQL 容器尚未执行验证。微信真机分享、微信登录、朋友圈、海报保存权限仍需微信开发者工具与真机验证。H5测试不等同于微信平台验证。
